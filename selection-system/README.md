# 경기지역본부 실시간 이력서 선정 시스템 — 시범판

## 현재 상태
- 2026-10-29 평택 고덕 우미건설 36BL 공고는 `selection-notices/2026-10-29-umi36bl.json`에 저장됨
- 공고 데이터 `status`는 `draft_waiting_for_live_registration_backend`로 접수 미개통
- 기존 `data.json`의 `seq`/성명/지부와 실시간 대조하여 순위 정렬
- **이름 + 지부 + 생년월일 6자리(YYMMDD)**를 비공개 참석자명부 인증명단과 서버에서 대조한 경우에만 접수
- 비공개 인증명단은 별도 구글 시트로 유지하고 생년월일은 GitHub·공개 순위표·접수 저장 시트에 기록하지 않음
- 접수 기록은 Google Apps Script 소유자의 **별도 Google Sheet**에 기록됨. GitHub data.json은 수정하지 않음
- 2026년 10월 29일 오전 10시(Asia/Seoul) 이후 서버에서 접수 차단

## 최초 1회 설치: 관리자가 해야 할 일
1. Google 계정으로 https://script.google.com 접속 → **새 프로젝트**.
2. `Code.gs`의 기본 파일 내용을 이 폴더의 `Code.gs` 전체 내용으로 교체.
3. HTML 파일을 **Index**라는 이름으로 추가하여 `Index.html` 전체 내용 붙여넣기.
4. 프로젝트 편집기에서 `setup` 함수를 선택하고 **실행** → Google 권한 승인. 실행 로그에 생성된 스프레드시트 URL이 표시됨.
5. Apps Script **프로젝트 설정 → 스크립트 속성**에서 `AUTH_SHEET_ID`에 기존 비공개 `참석자명부_인증용_비공개`의 스프레드시트 ID를 설정. **ID를 GitHub 코드나 공개 공고문에 쓰지 말 것.** 해당 시트에는 `인증명단` 탭과 A열 `성명`, B열 `소속지부`, C열 `생년월일(YYYYMMDD)`이 있어야 함. 실행 계정에 이 파일을 읽을 권한이 있어야 함.
6. 우측 상단 **배포 → 새 배포 → 유형: 웹 앱**. 실행 사용자: **나**; 액세스: **모든 사용자**. 배포 후 `/exec` 주소 복사.
7. ChatGPT에게 `/exec` 주소를 알려주기. ChatGPT가 공고 JSON의 `status`를 `open`으로 바꾸고 아래 고유 링크를 발급.
8. 오픈채팅에 **공고문 + 링크** 공유.

## 링크 형태
`https://script.google.com/macros/s/배포ID/exec?id=2026-10-29-umi36bl`

실제 배포ID를 알기 전에는 접수 링크가 존재하지 않습니다. 임의의 가짜 URL을 쓰지 마세요.

## 향후 공고 등록
ChatGPT가 이 폴더의 기존 공고 형식에 맞춰 `selection-notices/<공고ID>.json`을 추가하고,
사용자는 동일 웹 앱 배포 주소에 `?id=<공고ID>`를 붙여 전달합니다.
신청자 이름·지부를 실시간 확인하고 최소 약 15초마다 희망자 순위가 갱신됩니다.

## 운영상 주의
- **시험판**은 이름·지부·생년월일 6자리 확인으로 허위 신청을 줄이지만, 타인의 생년월일을 아는 사람이 대신 신청할 수 있습니다. 법적/강한 본인인증이 아니므로 필요 시 별도 인증 수단을 추가하세요.
- 인증 실패는 같은 이름·지부 기준으로 30분 동안 최대 5회까지만 허용(비공개 캐시). 생년월일 원본은 저장하거나 로그에 출력하지 않습니다.
- 조합원 명단과 대기순번 명단에 모두 존재해야 신청할 수 있고, **두 명단의 업데이트 시점이 다르면** 관리자 확인이 필요합니다.
- 운영 중 기존 참석자 인증명단의 읽기 권한을 넓히지 마세요. 응답은 검사 결과만 전달합니다.
- 공개 URL 접속자는 신청자 성명과 지부, 대기순번을 볼 수 있습니다. 공개 범위를 검토하세요.
- 현재 대기순번 기준 정렬은 `data.json.seq` 오름차순만 적용합니다. 인센티브/예외/자격요건 판정은 최종 선정 시 관리자가 확인합니다.
- 비희망은 수집하지 않으며 동일 공고/지부/성명의 중복 신청을 차단합니다.
- Google Sheet의 신청 이력 수정·취소는 관리자가 수행해야 합니다. 신청자는 직접 취소할 수 없습니다.
- 카카오톡 오픈채팅 자동 메시지 전송은 포함되지 않습니다. 관리자 알림과 오픈채팅 발송은 별개입니다.
- Apps Script 및 Google Sheets 할당량/서비스 장애로 제출이 지연될 수 있습니다. 마감 직전 접수 시 주의해야 합니다.
